# This repository is associated with a yet unpublished paper

## List of files and what they are
- Clean_BGC_GCF_isolation_source_summary.csv - BGC summary created by lsaBGC-Pan with isolation source from NCBI and in-house strain collection added to table
- KEGG_pathways_persistent.tsv - All unique KEGG pathways identified for the core/persistent Microbispora pangenome 
- KEGG_pathways_variable.tsv - All unique KEGG pathways identified for the non-core/variable Microbispora pangenome
- MICB.emapper.clean.zip - eggNOGmapper annotation output for all genes in the Microbispora pangenome
- gtdbtk.unrooted.itol.clean.tree - The phylogenetic tree created by GTDBtk2, which was used for visualisation in iTol
- gtdbtk.unrooted.itol.* files - Datasets to overlay onto the iTol tree
- GCF_Heatmap.iTol.clean.txt - iTol compatible visualisation of Gene Cluster Families (GCFs) identified by lsaBGC-Pan
- pairwise_fastani_results_final_021225.clean.txt - fastANI results for pair-wise comparison between all genomes
- PanGenome-MICB.All.prt-clust-0.8-mode1-th8.clean.lst - List of all gene families identified by PanACoTA
- PanGenome-MICB.All.prt-clust-0.8-mode1-th8.lst.quali.clean.txt - Qualitative matrix of all gene families identified by PanACoTA by genome
- PanGenome-MICB.All.prt-clust-0.8-mode1-th8.lst.summary.txt - Quantitative matrix of all gene families identified by PanACoTA by genome
- PersGenome_PanGenome-MICB.All.0.8-mode1.0.95.clean.lst - PanACoTA - List of all gene families identified by PanACoTA at 95% conservation
- PersGenome_PanGenome-MICB.All.0.8-mode1.0.95-multi.clean.lst - List of all gene families identified by PanACoTA at 95% conservation allowing for multiple copies
- PersGenome_PanGenome-MICB.All.0.8-mode1.1.clean.lst - List of all gene families identified by PanACoTA at 100% conservation
- PersGenome_PanGenome-MICB.All.0.8-mode1.1-multi.clean.lst - List of all gene families identified by PanACoTA at 100% conservation allowing for multiple copies
